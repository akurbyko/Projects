# Цифровой помощник тьютора

Тестовое задание на стажировку по направлению Project Management.

## О проекте

Цель проекта — разработка цифрового помощника, который позволит собирать наблюдения о состоянии ребёнка, отслеживать изменения и использовать накопленные данные для формирования AI-подсказок.

## Что сделано

В рамках тестового задания я:

- сформировал вопросы к заказчику и стейкхолдерам;
- описал основной процесс внесения наблюдений и составил BPMN-схему;
- подготовил примерный план работ на двухмесячный пилот;
- выделил основные риски;
- описал, как бы я организовал работу с командой и заказчиком.

## Файлы

- `Test Tutor.pdf` — основная часть тестового задания;
- `Motivation Tutor.pdf` — мотивация участия в проекте.

## О решении

При выполнении задания я старался в первую очередь разобраться в требованиях проекта, определить основные вопросы и понять, как можно организовать работу команды в рамках двухмесячного пилота.

В BPMN-схеме показан один из основных сценариев работы с наблюдениями. Схема не охватывает все возможные варианты и при дальнейшей работе над проектом может быть дополнена.
