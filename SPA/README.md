# SPA Inventory & Procurement Assistant

Тестовое задание на стажировку в роли Project Manager / Business Analyst.

Проект посвящён MVP AI-помощника для планирования закупок и управления запасами сети SPA.

## Что сделано

- подготовлены вопросы для уточнения требований;
- описан основной пользовательский сценарий;
- составлена дорожная карта пилота на 2 месяца;
- определены ключевые риски;
- подготовлены контрольные сценарии и метрики приёмки MVP;
- описан процесс работы с командой и заказчиком.

## Файлы

- `Test SPA.pdf` — выполненное тестовое задание;
- `Motivation SPA.pdf` — мотивационная часть.

## О решении

При выполнении задания я старался в первую очередь разобраться в требованиях проекта, определить основные вопросы и понять, как можно организовать работу команды в рамках двухмесячного пилота.

В схеме показан один из основных сценариев работы AI-помощника — от запроса пользователя и расчёта потребности до получения рекомендации по закупке. Схема не охватывает все возможные варианты и при дальнейшей работе над проектом может быть дополнена.

В дорожной карте основной акцент сделан на Discovery, так как в исходных требованиях остаётся ряд вопросов к текущим процессам, источникам данных и бизнес-логике расчётов.
